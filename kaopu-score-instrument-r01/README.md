# KAOPU Score Instrument R01

这是一个从零开始、与旧对象生产线隔离的可证伪实验。目标不是先证明“任何对象都能被极短谱子完整记录”，而是先验证下面四件事：

1. **谱与乐器能否彻底分离**：谱中不保存顶点、三角面、贴图或外部模型；乐器只依据谱实时生成三维对象。
2. **同谱能否稳定复述**：相同的 `K1` 谱与相同版本乐器必须产生相同对象。
3. **信息能否被有效压缩**：谱的 UTF-8 字节数、生成对象数、顶点数、三角面数与扩展倍率都必须可见。
4. **语法能否逐步传递**：同一套基本语法先演奏方体、球体、柱体、圆锥、圆环、组合与重复阵列，再决定是否值得进入真实物种。

## 必须先纠正的前提

信息不会凭空消失。极短谱子成立的条件，是大量共同知识已经被固化在乐器中。谱越短，乐器承担的先验、默认值、生成算法和对象语法就越多。

因此 R01 只能证明：对于乐器已经认识的几何语法，少量参数可以展开为较复杂的三维结果。它不能证明鱼、珊瑚、鸟或地形已经可以用同样长度的谱精确复述。真实对象还需要自己的测量、结构语法、材料语法、运动语法和验证器。

## K1 谱格式

谱必须带版本头：

```text
K1|<节点>;<节点>;...
```

### 基本几何

```text
b宽,高,深      方体
s半径          球体
c半径,高度     圆柱
n半径,高度     圆锥
t主半径,管半径 圆环
p宽,深         平面
```

所有尺寸单位为米，Y 轴向上。尺寸可以省略，乐器会使用 K1 固定默认值。

### 可选属性

```text
#颜色       例如 #d69a5a 或 #da5
!粗糙,金属  例如 !.7,.05
@x,y,z      位置，单位米
/x,y,z      欧拉旋转，单位度
%x,y,z      缩放
```

属性顺序固定为：颜色 → 材质 → 位置 → 旋转 → 缩放。未写出的属性使用 K1 默认值。

### 逻辑算子

```text
A数量,半径{子谱}   围绕 Y 轴的环形阵列
L数量,间距{子谱}   沿 X 轴的线性阵列
```

逻辑算子可以包含多个子节点，并可嵌套。

### 示例

```text
K1|b#d69a5a
K1|s.62#5b9bd5
K1|c.45,1.25#6ea870
K1|t.68,.19#c87883
K1|A12,1.2{c.10,.65#e7b34e@0,.15,0/25,0,0};s.32#f4e2b8
```

## R01 边界

- 不加载 GLB、纹理、图片或旧项目代码。
- 不保存任何最终几何结果。
- 不引入鱼、珊瑚、鸟、植被或地形的专用知识。
- 不把相机、灯光和地面混进对象谱；这些由当前世界乐器负责。
- 不把本轮简单几何成功误判为真实物种成功。

## 后续判定

只有当 R01 同时满足可运行、确定性、无隐藏资产、字节统计正确、桌面与移动端可操作，才进入 R02。R02 再比较“可读谱”与“紧凑编码谱”，避免过早追求不可读的极限压缩。
