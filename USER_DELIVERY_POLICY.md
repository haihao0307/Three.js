# User delivery policy

Every routine user-facing production workbench delivery in this repository contains one verified public URL only.

The URL must be directly clickable and automatically open the final interactive workbench. Related scenes, modules, systems, and review modes must be reachable inside that one workbench.

Do not include downloadable HTML files, ZIP archives, full packages, sandbox links, screenshots, hashes, manifests, QA reports, repository file views, setup instructions, or multiple test URLs unless the user explicitly requests that specific material.

Internal packages, source files, hashes, screenshots, manifests, and QA evidence may continue to be generated and stored for engineering verification. They remain hidden from routine user-facing replies.

Before sharing the URL, verify public HTTP access, final redirect behavior, critical resources, real-browser startup, and the requested interaction. A local file or successful build does not qualify as delivery.
